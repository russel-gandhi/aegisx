<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer shell → Postgres container | `docker compose exec psql` runs statements as the database owner. Input is developer-authored static SQL files, not user input. |
| host filesystem → container | `./infra/postgres/initdb` is bind-mounted read-only and auto-executed by the image at init. Any file landing in that directory runs as the Postgres superuser on first boot. |
| `.env` → compose interpolation | `POSTGRES_PASSWORD` crosses from an untracked local file into container env and into `PGPASSWORD` for exec calls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
