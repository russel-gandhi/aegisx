# Phase 06.1 Plan 08: Copilot-Driven Navigation -- Deep Links + Cancellable Auto-Navigate (D-13) Summary

**Every Copilot evidence citation is now a working deep link built from a single closed client-side route map (`lib/navigation.ts`), and an unambiguous answer offers one announced, WCAG-2.2.1-cancellable auto-navigate jump that fires only after the grounded answer has rendered -- closing D-13 across `EvidenceView`, a new `AutoNavigateNotice` component, and `?system=`/`?document=`/`?node=` deep-link landing on both `Knowledge.tsx` and `BlastRadius.tsx`.**

## Accomplishments

- `lib/navigation.ts`: `DESTINATION_LABELS`, `NAVIGATION_ROUTE_BUILDERS`, `terminalGraphNode`, `navigationHref`, `evidenceHref`, `evidenceLinkLabel` -- the one place in the frontend a Copilot destination address is formed. Both identifiers are `encodeURIComponent`-encoded in both route builders; an unrecognised `kind`/`evidence_type` returns `null` and navigates nowhere rather than guessing
- `EvidenceView.tsx`: each citation for which `evidenceHref` resolves renders a neutral `slate`-only react-router `<Link>` labeled `evidenceLinkLabel`; a citation that resolves to nothing renders as plain text with no disabled-looking affordance -- gains a required `systemId` prop, the one the page sent with the request, never inferred from the response
- `AutoNavigateNotice.tsx`: the D-13 notice -- `role="status" aria-live="polite"`, a single 3000ms `setTimeout` armed exactly once behind a `useRef` (survives React StrictMode's double-invoked effects), cleared on unmount, `Stay here` cancels permanently and replaces the notice with `CANCELLED_COPY`; no `setInterval`, no countdown, no `window.location`
- `ChatMessage.tsx`: renders the notice after `EvidenceView` (never before the answer), threading the new `systemId`/`autoNavigateArmed`/`onNavigationCancelled` props through
- `Copilot.tsx`: `navigationCancelled` state arms auto-navigation only for the newest assistant message; typing in the composer cancels the pending navigation the same way `Stay here` does (WCAG 2.2.1 Timing Adjustable) -- `matchHeroQuery`/`streamAssuranceCards` untouched
- `BlastRadius.tsx`: `?system=` read as a validated initial value alongside the existing `?node=` contract -- exactly one line replaced, nothing else in the file touched
- `Knowledge.tsx`: `?system=` preselects the upload system selector (validated against `KNOWLEDGE_SYSTEM_IDS`); `?document=` highlights the matching row with `HIGHLIGHTED_ROW_STYLE` (`ring-1 ring-slate-500`, a neutral ring, no accent hue) -- an unmatched id degrades to the ordinary list, never an error
- 91 new/updated tests across five files (`navigation.test.ts` 24, `EvidenceView.test.tsx` +4, `AutoNavigateNotice.test.tsx` 8, `Copilot.test.tsx` +3, `Knowledge.test.tsx` router-wrapper only, `deepLinkLanding.test.tsx` 10); full frontend suite green at 237/237, `tsc -b --noEmit` clean, `npm run lint` exit 0 (warnings only, matching pre-existing codebase convention)
