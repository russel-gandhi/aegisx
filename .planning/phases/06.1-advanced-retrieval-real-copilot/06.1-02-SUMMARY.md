# Phase 06.1 Plan 02: Real A1 Retrieval + POST /api/copilot/investigate + navigation_target Summary

**A1 now performs real Qdrant dense-vector retrieval instead of an existence check, `POST /api/copilot/investigate` is the first live HTTP caller of the compiled `StateGraph` and synthesizes a grounded, citing answer through the previously-dormant `task="synthesis"` provider slot, and the response carries a deterministic `navigation_target` computed in pure Python whenever every citation resolves to one unambiguous document or graph entity.**

## Accomplishments

- `app/retrieval/hybrid_search.py`: `hybrid_retrieve()` -- embeds the query, runs a real Qdrant dense search scoped to `system_id`, hydrates every hit from Postgres by `chunk_id` (never trusting the Qdrant payload), applies the `DENSE_RELEVANCE_THRESHOLD` gate deterministically, and returns at most `MAX_EVIDENCE_ITEMS` Section 15.7 evidence dicts ordered by descending score, plus a six-`stage_id` trace table (`combining`/`reranking` always `skipped` in this plan -- 06.1-03 fills them behind this same seam)
- `app/agents/minimal_specialists.py`: `run_a1` gets its own real body (no longer delegates to `run_specialist`); `SPECIALIST_CONFIG["A1"]["mode"]` `"existence"` -> `"retrieval"`; `_a1_abstain_finding()` preserved byte-identical as the degraded-mode return for pool-unavailable / unknown-system / unexpected-exception paths
- `app/graph/state.py`: `AgentState` gains `retrieval_evidence`/`retrieval_trace` accumulator fields (same `operator.add` reducer rationale as `findings`); graph topology (`add_node`/`add_edge`/`route_specialists`) is byte-for-byte untouched across all three tasks
- `app/routes/copilot_query.py`: `POST /api/copilot/investigate` -- guard order 422 (missing `system_id`) -> 503 (Postgres unreachable) -> 404 (unknown system) -> 504 (graph timeout); the blocked path returns C2's real `detect_injection()` reason with zero fabricated evidence; the insufficient-evidence path returns the UI-SPEC Copywriting Contract answer verbatim with zero synthesis calls (D-09); the grounded path synthesizes via `call_llm(task="synthesis")` through a local `_safe_call_llm`-style guard, falling back to a deterministic Python-composed answer when synthesis degrades, echoes JSON, or replies the literal word `INSUFFICIENT`
- `evidence_support_band()`: `HIGH`/`MODERATE`/`LIMITED`/`INSUFFICIENT_EVIDENCE` graded in Python from the top surviving evidence's `reranker_score` (falling back to `dense_score`), kept deliberately separate from C1's own compliance confidence
- `compute_navigation_target()` (D-13): the deterministic single-unambiguous-destination rule -- fails closed in five distinct ways (insufficient evidence, empty evidence, two-or-more competing candidates, an item that resolves to no candidate, an unrecognised `evidence_type`); a graph edge landing on an already-cited document collapses onto that same document candidate rather than reading as a second destination; `split_node_id`'s first-colon-only partition is reused (not re-implemented) so an entity id containing a colon round-trips correctly
- 69 new/updated tests across three files (`test_hybrid_search.py`, `test_minimal_specialists.py` additions, `test_routes_copilot_investigate.py`); full backend suite green at 453 passed (409 pre-existing baseline + 44 new), zero regressions
