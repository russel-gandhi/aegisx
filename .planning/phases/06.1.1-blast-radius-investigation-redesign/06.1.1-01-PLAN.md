<objective>
Wave 1 tracer: prove the redesigned information architecture end-to-end on real data with the smallest
change that does it. Add an investigation header (what are we investigating), restructure the impact
summary card, fix the React Flow attribution watermark (D-05 — the user's explicit, one-line-fixable
complaint), add semantic (not decorative) node coloring for a small fixed state set, restructure node
sizing and labeling so nodes are readable without extreme zoom (D-06's "larger, readable nodes" and
"clear type/identifier/description hierarchy", ROADMAP success criterion 2 — currently nodes have no
explicit style.width/height/fontSize and their label is the raw `node.node_id` string, per
06.1.1-RESEARCH.md), and complete the `?system=` deep-link round-trip CONTEXT.md's D-08 assumed already
existed (research found it does not — `BlastRadius.tsx` only *reads* `?system=` on initial mount, never
writes it on selector change).

This tracer intentionally does NOT touch the investigation panel content, relationship explanations, or
path highlighting (D-07) — those are Wave 2. It does not touch Copilot-navigation (D-09) — that is Wave 3,
gated on this wave landing. Every number and identifier used here already exists in
`EvidenceGraphResponse`/`BlastRadiusResponse` (verified in 06.1.1-RESEARCH.md); this wave is presentation
and IA only, per D-12 (no backend graph-construction changes).

Non-goals (D-11, explicit): no glassmorphism, no gradients, no glowing borders, no generic metric cards
beyond the four real numbers Bible §14.3 already specifies, no new component library.
</objective>
