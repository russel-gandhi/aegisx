<critical_findings>
**The exact arithmetic every fixture in this plan is calibrated against.** With `ALCOA_DIMENSION_COUNT = 9`: score starts at 100, loses 10 per false dimension, loses a further 100 when policy does not corroborate, and grades `HIGH` above 80, `MEDIUM` at 50 or above, `LOW` above 0, and `INSUFFICIENT_EVIDENCE` otherwise. Two consequences drive the boundary fixtures below: 7 true dimensions lands exactly on 80, which is `MEDIUM` because the threshold is exclusive; and 9 true dimensions with policy contradicting lands exactly on 0, which is `INSUFFICIENT_EVIDENCE` because that threshold is also exclusive. Both boundaries must have a test.

**The EVID-02 fixture must use real state, not a hand-built dict.** D-04 requires the contradiction case run against the real DB record and the real OPA evaluation. Plan 03-04's `DOC-2026-URS-01` fixture makes this possible with no invention: that row genuinely exists and its status is genuinely `APPROVED`, and Rego rule 1 genuinely does not fire on it. A finding that asserts a documentation-approval gap against that record is therefore a real contradiction — real row says approved, real policy engine says nothing — and must score `INSUFFICIENT_EVIDENCE`.

**Fail closed, and prove it.** When the OPA sidecar is unreachable, the Phase-2 client degrades to a fallback that returns an empty violation list. C1 must treat that as "not corroborated", so every finding scores `INSUFFICIENT_EVIDENCE`. That is the safe direction and it must be asserted, because the opposite failure — treating an empty violation list as agreement — would silently mark everything trusted the moment the policy engine went down.
</critical_findings>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent-produced finding -> C1 verification | A finding is untrusted model-influenced data; C1 is the boundary at which it becomes trusted or is refused |
| OPA sidecar availability -> confidence outcome | An external service outage must not be able to manufacture agreement |
| finding-supplied identifiers -> evidence lookup | A rule id selects a table and a record id selects a row, both from data that passed through a model |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-23 | Spoofing (fabricated evidence accepted) | `verify_finding` evidence lookup | critical | mitigate | A record id with no matching row short-circuits to INSUFFICIENT_EVIDENCE before any policy call; asserted by a call-counting wrapper proving the policy engine was never consulted (Task 1). |
| T-03-24 | Tampering (policy outage read as agreement) | OPA client fallback path | critical | mitigate | The Phase-2 client degrades to an empty violation list; C1 treats that as not corroborated, so all ten findings grade INSUFFICIENT_EVIDENCE with the sidecar down (Task 2 fail-closed test). |
| T-03-25 | Spoofing (contradicting claim graded as trusted) | `calculate_confidence` policy penalty | critical | mitigate | The −100 penalty guarantees INSUFFICIENT_EVIDENCE even at 9-of-9 ALCOA; covered by a per-dimension-count sweep and by the exclusive-above-0 boundary test (Task 1). |
| T-03-26 | Tampering (SQL injection via rule id) | `fetch_evidence_record` table selection | high | mitigate | An unrecognised rule id resolves no record and builds no statement; table names come only from the frozen ten-entry allowlist and record ids bind through a placeholder (Task 1 guard + test). |
| T-03-27 | Repudiation (unverifiable review claim) | SENT-2-12 close-out | medium | mitigate | The four Rule 6 coverage classes are named and located in `backend/README.md`, and the honest limitation — no live LLM produced the graded claims — is stated there rather than left implicit (Task 2). |
| T-03-28 | Denial of Service | ten-rule integration suite | low | accept | The suite makes ten live OPA calls against a local sidecar with the client's existing 2-second timeout; accepted as bounded local test cost. |
