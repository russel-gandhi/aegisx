## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user query -> A0 classification prompt | Free-form user text reaches a model whose output selects which agents run |
| model classification output -> `active_agents` | An externally-produced list controls graph fan-out |
| Postgres row content -> specialist narration prompts | Free-text columns reach model prompts across five more agents |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

A classification cannot introduce a node id the graph does not already own. |
| T-03-13 | Denial of Service | A0's classification call | high | mitigate | The 2000ms awaited timeout cancels the in-flight coroutine, and the router itself takes no retry beyond one cascade. Proven by the measured-elapsed-time test, not by inspection. |
| T-03-14 | Elevation of Privilege (indirect prompt injection) | specialist narration prompts | medium | mitigate | DB-sourced text is supplied as content to summarize, never as instructions; pass/fail is computed before any model call. C2's deterministic detector lands in Phase 5. |
