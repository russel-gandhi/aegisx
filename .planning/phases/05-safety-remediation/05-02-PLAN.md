Extend `backend/app/agents/c2_gateway.py` in place (do not create a second module). Add, below `PERMISSION_MATRIX`:

- `JAILBREAK_PATTERNS: Tuple[re.Pattern, ...]` — a module-level tuple of patterns compiled once at import. The first entry is Bible Section 2's verbatim example, transcribed exactly as written there including its `(?i)` flag and its three alternatives. Add a comment stating that this tuple is the only copy of the jailbreak phrase list in the repository and that a second copy drifting from it is the failure mode `opa_client.py`'s docstring already warns about for duplicated Rego logic.
- `ENTROPY_THRESHOLD_BITS_PER_CHAR: float = 4.5` and `MIN_TOKEN_LENGTH_FOR_ENTROPY: int = 12`. Both carry a comment block recording, in this order: that Bible Section 2 specifies "Shannon entropy calculations" but supplies no threshold, window, or minimum token length; that 4.5 was chosen because English prose sits well below it while base64 approaches `log2(64) = 6` and hex approaches `log2(16) = 4`; that 12 characters is the minimum length at which a token can carry a meaningful encoded instruction, and that it keeps ordinary hyphenated GxP record ids and UUIDs below the evaluation floor; and that this is recorded as assumption A1 in `05-RESEARCH.md`'s Assumptions Log, tuned against the fixtures in `test_c2_gateway.py` rather than asserted from any external standard. - `def shannon_entropy(text: str) -> float` — returns 0.0 for an empty string; otherwise `-sum((n / length) * math.log2(n / length) for n in Counter(text).values())`. Pure function, no I/O.
- `def detect_injection(text: str) -> Optional[str]` — returns a reason string when injection is suspected and None otherwise. Regex leg first: for each pattern in `JAILBREAK_PATTERNS`, `if pattern.search(text): return f"regex_match:{pattern.pattern}"`. Entropy leg second: for each whitespace-split token, `if len(token) >= MIN_TOKEN_LENGTH_FOR_ENTROPY and shannon_entropy(token) >= ENTROPY_THRESHOLD_BITS_PER_CHAR: return f"high_entropy_token:{token[:16]}..."` — the token is truncated so the reason string, which lands in an audit row, cannot itself carry the payload. Return None when neither leg fires. Docstring states that both legs are deterministic Python, that no model call occurs anywhere in this function, and that this is what Bible Section 2 means by "bypasses LLM interpretation entirely".

Update the module docstring: add `Requirement: SAFE-02` to the header line and replace 05-01's "injection detection lands in plan 05-02" line with a sentence describing the two legs now present.
